# Evensies: Split & Settle Up

Expense splitting for friends, roommates and trips. No daily limits, no ads, no data lock-in.

A group holds up to 50 people and an account up to 100 groups. These are anti-abuse caps, far above any real group: [ask](https://github.com/devyourown/evensies/issues) if you hit them.

- Source code (open source, Apache-2.0): [github.com/devyourown/evensies](https://github.com/devyourown/evensies)
- Support: [GitHub issues](https://github.com/devyourown/evensies/issues)
