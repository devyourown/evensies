# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue, pull request or discussion:

**[Report a vulnerability](https://github.com/devyourown/evensies/security/advisories/new)** (GitHub private vulnerability reporting)

If you can't use GitHub, email [support@nariinfo.dev](mailto:support@nariinfo.dev) with "Security" in the subject.

Only you and the maintainer can see the report. Please include:

- what is affected: the server, the iOS, Android or web app, or the deployment files;
- the version or commit, and the platform;
- the steps to reproduce it, ideally against a local server (see [CONTRIBUTING.md](CONTRIBUTING.md#development-setup)), and a proof of concept if you have one;
- what an attacker could do with it.

Please test only against your own local server. Don't access other people's data or degrade the official server for others.

## What happens next

This is a one-maintainer project, so replies are best effort: you should hear back within a week. We'll confirm the problem, agree on a fix and a disclosure date with you, and credit you in the advisory unless you'd rather not be named.

## Supported versions

| Version | Supported |
|---|---|
| `main` | yes |
| the latest store release, once there is one | yes |
| anything older | no; please update |
